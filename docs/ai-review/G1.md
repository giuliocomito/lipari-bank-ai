# AI Code Review: Giorno 1

Il codice viene dal Code Blueprint; l'ho portato nel progetto con un assistente, che ha
scritto anche il README e l'estensione. Le voci sono le quattro della giornata.

| # | voce | rilievo | decisione |
|---|---|---|---|
| 1 | dipendenze | Tutte usate: `fastapi`, `uvicorn[standard]` e `pydantic-settings` dall'applicazione; `ruff`, `mypy`, `pytest`, `pytest-asyncio` e `httpx` da controlli e test. | nessuna modifica |
| 2 | dipendenze | `uvicorn[standard]` porta con sé anche `websockets` e `httptools`, oggi superflui. | non corretto: l'extra serve a `watchfiles` (il `--reload` del README) e a un server più veloce in produzione; sfoltirlo pacchetto per pacchetto costerebbe più manutenzione di quanto pesi |

| 5 | tipi | `uv run mypy src` passa in strict con il plugin di Pydantic; ogni funzione dell'applicazione è annotata. | nessuna modifica |
